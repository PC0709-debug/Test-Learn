Focus Mode shortcut

How to set it up (2 min)
  1. Open the Shortcuts app → tap +.
  2. Add the action Set Focus → choose Do Not Disturb → Turn On → Until Turned Off.
  3. Name it exactly Focus On (or match the name above).
  4. Make a second shortcut that turns it Off, named Focus Off.
  5. Turn the switch above on. When you tap Begin, Still opens the shortcut; tap ◀ Still in the top-left corner to come back.
